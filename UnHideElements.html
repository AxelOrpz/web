Support and Technical Assistance

General Functionality

What exactly does UnHideElements do?

It locates explicitly hidden elements ("Hide Element") in compatible Revit views (plans, sections, 3D), organizes them into a visual hierarchy (category > family > element), and allows them to be unhidden selectively with immediate visual confirmation.

Which Revit versions does it work with?

Compatible with Revit 2025+ thanks to its implementation with the latest Autodesk APIs.

Does it require complex configuration?

Zero configuration - It installs and automatically appears in the "DiFlow" tab in Revit.

Advanced Usage

How do I access advanced features?

When run, it displays a floating panel with:

  • List of views with hidden elements (left)
  • Hierarchical tree of elements (right)
  • Controls to expand/select/unhide

Why don't I see elements in certain views?

This may be due to:

  • Incompatible view (schedules, sheets)
  • Elements hidden by filters/templates (not explicitly)
  • Elements in groups or linked models
  • Temporary Hide/Isolate activated

How do I manage large quantities of elements?

Use our special controls:

  • "Expand All"/"Collapse All": Manage hierarchy
  • "Select All": Check all elements
  • Filter by view: Select specific views in the left panel

Troubleshooting

Elements do not appear after unhiding

Verify:

  • Filters applied in the view
  • View templates that override visibility
  • If elements belong to groups (requires manually unhiding the group)

Add-in crashes when opened in large projects

Optimize performance:

  • Avoid processing incompatible views (e.g., schedules).
  • Uses VirtualizingStackPanel in the TreeView (already implemented).

The "DiFlow" tab does not appear in Revit

Solutions:

  • Verify installation in C:\ProgramData\Autodesk\Revit\Addins\2024
  • Check for errors in Manage > Add-in Manager
  • If the installation was done from the official Autodesk App Store page, the add-in should automatically appear in the Add-Ins tab.
  • Download the latest version from our page

Technical Limitations

Does it work with linked model elements?

Not currently compatible - Only manages elements from the current model (due to Revit API restrictions).

Does it support schedules or tables?

No. Only graphical views: plans, sections, elevations, and 3D.

Can elements be unhidden by category?

Yes. In the hierarchical tree, check the category or family to unhide all its elements. Operations use reversible transactions (Transaction), allowing changes to be undone with Ctrl+Z.

Master UnHideElements in 5 Minutes

Quick Visual Guide:

  1. Start: Click on DiFlow > Hidden Elements > UnHideElements
  2. Select view: Choose a view from the left panel
  3. Explore: Navigate through categories → families → elements
  4. Select: Check individual elements or entire categories
  5. Action: Click Unhide Checked Elements to make them visible
